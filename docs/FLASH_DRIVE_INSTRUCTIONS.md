# Флешка 32GB - Інструкція для завершення

## Проблема

Флешка `/dev/disk14` не з'являється в системі після примусового вимонтування через `diskutil umount force`. Це може статися через:

1. Флешка була фізично відключена
2. Проблема з USB-портом або кабелем
3. Проблема з драйверами macOS
4. Пошкодження файлової системи

## Рішення

### Варіант 1: Підключіть флешку і запустіть скрипт

1. **Підключіть флешку** до комп'ютера
2. **Відкрийте термінал**
3. **Запустіть скрипт:**
   ```bash
   bash /Users/dev/Documents/GitHub/claw-code/format_flash_drive.sh
   ```

Скрипт автоматично:
- Знайде вашу флешку (32GB)
- Показає список доступних дисків
- Запитає підтвердження перед форматуванням
- Форматує диск у FAT32 з міткою "CLAW_USB"
- Підкаже точку монтування

### Варіант 2: Використовуйте Дискову утиліту

1. Відкрийте **Applications → Utilities → Disk Utility**
2. У лівому меню ви повинні побачити вашу флешку
3. Якщо диск не з'явився:
   - Спробуйте інший USB-порт
   - Перевірте, чи правильно підключено
   - Перевантажте комп'ютер
4. У Disk Utility:
   - Виділіть вашу флешку
   - Натисніть кнопку **"Етикетка"** (Label)
   - Введіть: `CLAW_USB`
   - Натисніть кнопку **"Скинути"** (Erase)
   - У меню "Формат" виберіть **FAT32**
   - Натисніть **"Скинути"** знову

### Варіант 3: Якщо флешка не з'являється

1. **Перевірте підключення:**
   - Відключіть і підключіть знову
   - Спробуйте інший USB-порт
   - Якщо є - інший кабель
   - Спробуйте інший комп'ютер

2. **Перевірте в System Information:**
   ```bash
   system_profiler SPUSBDataType | grep -A 5 -B 5 "32.*GB"
   ```
   - Якщо флешка не з'являється в списку - проблема з USB або драйверами
   - Можливо, потрібно оновити драйвери або перезавантажити систему

3. **Перезавантажте систему** (якщо є вага)

4. **Якщо флешка не працює** - можливо, вона пошкоджена і потребує заміни

## Після форматування

Якщо форматування успішно завершено:

1. **Точка монтування буде показана в терміналі**
2. **Відкрийте диск у Finder:**
   - Натисніть Cmd+Shift+G
   - Введіть точку монтування
   - Наприклад: `/Volumes/CLAW_USB`

3. **Копіюйте архіви:**
   - Архіви знаходяться в: `/Users/dev/Downloads/`
   - Архіви для копіювання:
     ```
     HURMA+LIUBOV.zip.zip (39 MB) - має '+' у назві
     HURMA LIUBOV.zip (39 MB)
     ```

4. **Перевірте цілісність:**
   - Скопіюйте архіви на флешку
   - Відкрийте термінал у папці флешки
   - Перевірте розміри файлів
   - Перевірте цілісність командою:
     ```bash
     unzip -t "ім'я_архіву.zip"
     ```

## Підтримка

Якщо у вас є проблеми:

2. Спробуйте інший USB-порт
3. Використовуйте Дискову утиліту
4. Оновіть драйвери macOS
5. Перевантажте систему
